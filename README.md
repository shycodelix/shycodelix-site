# shycodelix site

    npm install
    npm run dev

- `/` the desktop: Windows XP-style window manager, pixel wallpaper, terminal, Minesweeper, Avante case study.
- `/profile` reader mode: the same content as a plain, printable page.
- Content lives in `app/data.js`. Photos in `public/photos`, brand assets in `public/avante`.

When updating the site, replace this folder (or run `npm install` if `package.json` changed).
